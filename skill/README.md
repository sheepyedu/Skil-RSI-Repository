# Context-management skills

Default English edition · [中文版](../skill_zh/README.md)

This umbrella directory contains all skill-related materials previously stored in `Context 管理 skills/` and `初始 skill/` (the earlier collection referred to as “push skill”). Raw experiment archives, results, and runner source remain in their original repository locations.

- [Initial skills](initial-skills/README.md): 10 candidates from the initial review of native Claude Code grouped/shuffled trajectories, 200 executions of 100 independent tasks and 19 native compactions.
- [Four-platform context management](context-management/README.md): 25 candidates from the subsequent comparative review, with seven for Claude Code and six each for Claude Code CLM, Codex, and Codex CLM.
- [WorkBuddy context management](workbuddy/README.md): four candidates for Codex, Codex CLM, native Claude Code and Claude Code CLM, derived from 65 Codex and 60 Claude Code pairs.
- [Evidence](context-management/EVIDENCE.md), [evaluation protocol](context-management/EVALUATION.md), and [research indexes](context-management/references/README.md): research-only material, not installable runtime memory.

Every individual skill directory includes SKILL.md and a README explaining derivation, applicability, and limits. English and Chinese editions have identical relative paths. Install only one language edition of selected skills; do not install both as duplicate active rules. Keep README and research artifacts out of the evaluated agent's accessible runtime/search environment. These are unvalidated candidates, not proven improvements. This reorganization ran no new benchmark and changed no runner.
