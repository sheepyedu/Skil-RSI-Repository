# Verified between-task context maintenance for Codex CLM

Use this candidate for a long-lived agent with a real request-projection editor. It is not the WorkBuddy plugin, a runner change, or a replacement for native Codex context management. Install only one language version. Do not load this README, the validation fixtures, or historical rollouts into every task.

**Where it came from.** This revision was distilled from an offline review of four WorkBuddy configurations: native Codex, Codex CLM, Codex CLM with a skill path hint, and Codex CLM with controller-scheduled maintenance. Verified projection and verified downstream use were treated as separate outcomes. The observed score ranking is not a controlled estimate of the skill or plugin effect.

**Transferable part.** Treat a boundary as a safe opportunity rather than an obligation. Write the smallest note that serves a later decision, and verify actual delivery and retrieval. Keep the policy separate from scheduling and benchmark-specific instructions. The observed cadence of two tasks is not a recommendation for other workflows.

**Adoption.** Test the [fixtures](references/validation.md) before deploying. Measure preservation, downstream use and cost separately; roll back if the skill blocks completion, causes stale-state reuse, or removes evidence that cannot be recovered.
