# Codex CLM context-management skills

These six candidate skills were generated from offline raw-trajectory review, not from a new intervention experiment. The source is the Codex CLM 100-task run and same-order native Codex comparison. Use these skills only with this repository's custom `clm-context` gateway; native Codex does not provide this interface.

Each skill documents triggers and the generation, use, feedback, and revision loop, with applicability limits and rollback. Follow the [evaluation plan](../EVALUATION.md) for independent validation. Read [evidence](../EVIDENCE.md) offline only.

Copy only selected skill directories into a runtime. Do not install the research evidence, event indexes, evaluation materials, or benchmark answers into the tested environment or its search paths.
