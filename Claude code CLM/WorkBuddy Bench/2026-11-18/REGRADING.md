# 上游中断后的 WorkBuddy 补评

2026-11-18 北京时间，第 5 题 CLM 组的 `risk_level_derivation` 评分项原先因连续五次流内上游错误被按空判负。补评使用同一份冻结产物、同一份题面和同一个模型 `gpt-6.1-sol`。

| 阶段 | 结果 |
|---|---|
| 原始正式评分 | 5 次流内错误，该项按空判负，CLM 得分 0.5 |
| 原始请求重试 | 原始字节逐字重放 3 次，仍出现流内上游错误 |
| 非流式重试 | 保持消息、评分模型、输出要求及采样参数，切换非流式。首次超时无响应字节，第二次 HTTP 200 并完整返回 |
| 官方规则重算 | 目标项判为通过，其余 10 项保留。原始评分规则重建精确复现 0.5，补评后得分 0.8，通过 10/11 项 |

复核了归档工作区文件和官方 artifact 完成条件。采用上游固定版本的 `submit_result.py`、`finalize_eval.py` 原评分路径重算。原生组得分 0.8，本题修正配对差为 0。原始评分、全部失败与成功的响应照常保存在 H20，原题的 DeepSeek 答题轨迹继续按已归档版本使用。
