# WorkBuddy 原生 Claude Code：可恢复的工作状态

**适用场景：** 可能跨压缩、中断或交接的原生 Claude Code 长任务。技能约束工具返回范围、保存未完成状态，并在续跑后核实准确产物。不需要自定义上下文编辑器。

**归纳来源：** 配对审阅原生和 CLM 的执行轨迹，重点追查原生压缩、验证和恢复。第 56 题原生从本地容量故障恢复；第 21–25、39 题表明，当前源约束和实际回读比记住一句“已通过”更有用。审阅另发现局部自测无法消除的评分器启动故障。见[逐对审阅](../CLAUDE-CODE-EVIDENCE.md)。

**泛用范围：** 代码库迁移、长程故障排查、有可恢复产物的文档或构建流程。短任务没有需保留的状态时不触发。

**安装：** 只复制 `SKILL.md` 到 Claude Code 的同名技能目录，例如适用的项目 `.claude/skills/`。中英文只装一版；README、题目和审阅材料都留在运行时检索范围外。未做真实技能开关评测。
