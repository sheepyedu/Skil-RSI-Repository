# WorkBuddy Codex CLM：可核验的活动上下文编辑

**适用场景：** 运行时明确暴露编辑契约的 Codex CLM。如果没有编辑器或没有可靠的上下文视图，就退回到检查点方案。本技能不实现 CLM 训练或 SCR。

**从哪一步归纳：** 把接受的主动编辑、仅查看以及自动压缩分开审阅，再检查后续视图和实际用法。本次轨迹可见第 1、51、54 题三次接受的主动编辑。第 36 题识别到保留的旧笔记无关，却未修订。第 54 题更新了笔记，后续工具回显了它，但一次可能复用的任务并未执行笔记里的核验动作。见[离线逐对审阅](../EVIDENCE.md)。

**可迁移机制：** 只做规模最小、必要状态可恢复的编辑；分三步看编辑器有没有接受、后续视图有没有反映、工作有没有实际用到它。如果运行环境不提供投影视图或回滚，要说明边界，并先核验恢复来源。

**安装：** 只复制这个目录的 `SKILL.md` 到同名技能目录，中英文只装一版。README、审阅材料和基准产物都留在评测运行时检索范围之外。原对比未安装这个技能，不能当作已验证的提分结果。
