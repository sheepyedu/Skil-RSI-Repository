# Codex CLM：小步编辑，核验真实生效

区分送给模型的活动上下文、持久检查点和执行原始记录。编辑回执不能证明下一次请求看到了什么。原生保护性压缩不是模型主动做出的 CLM 编辑。不要改原始执行记录来冒充编辑活动上下文。

## 非紧急记忆编辑优先放在题目边界

- 非紧急的持久记忆重写、上下文裁剪，优先安排在上一题已交付且工具调用全部收尾后，或下一题开始读取新材料、发起首个任务执行调用之前。这是时机偏好，不要求每个边界都编辑，也不是已经证明能提升分数的方法。
- 题中正常使用工具、保存证据、写短期笔记和必要检查点不受影响。只有预计将触达上下文限制、关键状态即将丢失或无法继续执行时，才在题中编辑记忆；做最小可逆处理后继续当前题。
- 编辑前保留未完成义务、精确约束、证据定位与可恢复旧版或回滚指针。按下文进行保存、回读核验，并在下一题实质工作前检查有效上下文；边界无法安全完成生效及验证时，延后非必要编辑。

Codex CLM 的编辑入队后仍是待处理状态；在实际应用的请求核对修订版与投影，不把整理与题目实质执行交错进行。

## 先决定要不要改

- 明确现在的压力和下一步要做的决定。只有能指出挤占当前工作的旧片段、运行时提示容量压力，或测到了反复注入旧内容的成本，才考虑编辑。旧笔记是否应常驻，要问换一个领域的任务是否还需要它；不需要就只留带作用域的定位。不要为编辑而编辑；工具调用仍在进行、外部操作未确认或恢复条件不清时，保留活动尾部。
- 查实际工具契约及当前修订版。按字段查看修订版、上次接受的编辑、候选 ID/大小和受保护位置，不要只截状态输出的前几个字符。确认大小单位、上限，以及笔记是整份替换还是追加。没有编辑能力或状态不清时，留下短检查点，让原生运行时管理压缩；不要猜接口。
- 逐项分类：**保留**精确约束、未决状态、近期工具回执和无法找回的证据；**索引**可找回的大证据，留下作用域、版本和稳定定位；**移出**重复内容和已完成且可重现的输出。替代项验证后把过期项移出活动笔记；未解决的冲突保留标签和最省力的复查方法。

## 保存、编辑、验证

1. 有损编辑前先写最短检查点：`作用域/版本 | 目标和精确约束 | 已核验决定与定位 | 未决问题/操作 | 下一步如何确认`。回读，并从续跑时的环境验证最关键的定位。找不回的证据留在活动上下文。保存未获授权或失败时，不删除对应信息。
2. 用刷新后的 ID 编辑一段语义完整的内容。工具若整份替换笔记，从现有笔记派生新版本：保住仍有效的条目，明确退役过期项。先删重复输出，再考虑唯一证据；不做大范围盲剪，不碰受保护或仍活跃的记录。
3. 编辑入队只算待处理。检查真正应用编辑的下一次请求回执或状态，再看可见的上下文修订版或请求投影。检查必要信息能否用于下一步、目标片段是否确实移出或变短。看不到投影就标为未验证，不冒称生效。被拒后先找原因并刷新视图，不原样重试。
4. 出现丢失就停止继续剪裁。从已核验检查点或源证据恢复，标记失效的定位或笔记；下一步有依据后再继续。不虚构回滚功能，不凭含糊摘要重造精确内容，也不假定归档一定可检索。

## 验证记忆被使用，再修订规则

下一次有后果的操作前，分清“定位到了证据”“确实读了证据”“行动已核验”。检索先匹配当前作用域和准确实体，不只凭叙述相似。更新日期不能单独解决冲突：确认同一作用域后退役旧版，否则注明复查条件。记录编辑是否发起、接受、可见和有用，以及期间是否还发生了原生压缩。只在有测量数据时比较输入、缓存、时延和恢复成本。标明计数是本次还是累计，字节和 token 分开记录。编辑获接受或最终分数更高，都不能单独证明编辑有效。

例：冗长诊断输出仍可按固定版本的产物找回。先验证定位，保留准确的失败检查与定位，再移出重复输出。如果下一次请求缺了待办操作或硬约束，先恢复，不要继续剪裁。
