# Codex CLM：一次可恢复、可核验的编辑

## 适用与时机
明确压力和下一步决策。如果只收到技能路径且触发成立，先读目标版本；正文已在有效上下文中不重复读取。区分模型有效输入、持久记忆与执行证据，不改原始记录冒充编辑。

非紧急编辑优先在已交付且工具全部收尾后，或下一题尚未读材料、尚未发起首个实质调用前进行。计划或接近最终回复不等于完成。正常工具和短期笔记不受限。题中仅在即将触达容量、关键状态即将丢失或无法继续时做最小可逆处理，然后继续任务。

## 检查与选择
检查实际契约、修订版、字节/token单位、保留边界及笔记覆盖/追加语义。定向取修订版、编辑/应用状态、保护范围等结构化字段；不要简单截前N字符，也不把缺字段当作无事件。接口不明确则使用原生检查点，不猜命令。

分类：保留精确约束、未决操作、新近回执及无法重取的证据；为可重取大证据保留范围/版本/定位；移除已完成重复内容。删除前从恢复环境验证可重取性，不能找回就不删。单题笔记必须有限定范围与退出/失效条件。

## 保存、编辑、核验
保留旧笔记和检查点：实体/版本、硬约束、已核验与已尝试状态、未决副作用、证据定位、下一检查。确认回滚指针可用。整份覆盖时必须保留旧版仍有效内容；省略不等于保留。

用新鲜ID提交一次语义完整编辑，保护活跃工具调用及结果配对。区分提议、排队、生效、验证；提交同一批里的status可能仍是旧状态。在实际应用请求核对修订版与笔记/投影，再进行实质续跑；不可观察就明说。边界不能安全验证则延后非必要编辑。拒绝后刷新状态、查原因，不盲重试；丢信息后停剪并从已核验来源恢复。

## 复用与改进
按范围、对象、版本检索。失效替换并保留来源；不适用只跳过；暂缺依赖保留并标记受阻。未解冲突用最小区分检查，版本和权限变化重新核验。确认保留状态确实支撑下一动作，而不只看编辑获接受。

分别记录提示提供、正文暴露、适用、行动、确认与结果。区分原生压缩和CLM编辑、累计投影差和单次节约。只修断裂环节；获接受或高分都不能单独证明收益。

例：已结束的诊断输出可换成验证过的版本固定定位，但未决操作要保留精确信息，直到查到回执。
