# WorkBuddy Codex：可恢复的上下文

**适用场景：** 原生 Codex 的多阶段工作、原生压缩或中断后续跑，以及工作区状态变化后的恢复。不需要自定义上下文编辑工具；也不要求每轮写笔记。

**从哪一步归纳：** 配对对比相同顺序下的两组任务，再检查入选执行时间线从记录到行动的链路。原生第 31 题在任务中压缩，第 32 题随后仍能读取当前证据。第 28 题在未修改基线上复现相同错误，避免把局部测试误记为整个任务状态。第 38–39 题说明应核实当前环境能力，不能把一次失败当成永远不可用。见[离线逐对审阅](../EVIDENCE.md)。

**可迁移机制：** 检查点必须能回答下一步真正需要决定的问题，并指向可恢复证据。除了代码，也可用于报告交接、分阶段发布、多步骤文档处理。技能不扩大数据持久化权限。

**安装：** 只复制这个目录的 `SKILL.md` 到同名技能目录，中英文只装一版。README、审阅材料和基准产物都留在评测运行时检索范围之外。未做技能开关实验。
