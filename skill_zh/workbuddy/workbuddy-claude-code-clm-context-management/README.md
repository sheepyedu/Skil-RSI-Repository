# WorkBuddy Claude Code CLM：核验剪裁，也核验交付

**适用场景：** 能获准查看上下文或编辑状态的自定义 Claude Code CLM 运行器。区分输入压力、输出预算、传输中断和未交付。没有编辑器就用可核验的交接，不把它当成原生功能。

**归纳来源：** 本轮是控制器触发的题间写回，包含模型提议和运行器兜底，没有接受的题内编辑。审阅追查了超预算笔记、提议摘要中优先级写反、第 48 题容量恢复，以及响应正常但没有行动。这些支持按问题类型处理并核验保留状态，不代表编辑已经提分。见[逐对审阅](../CLAUDE-CODE-EVIDENCE.md)。

**泛用范围：** 有可回放检查点的多步编码、分析或其他 Agent 流程。使用任何运行器时，只操作能核实作用范围和契约的接口。

**安装：** 只复制 `SKILL.md` 到运行器支持的同名技能目录。中英文只装一版；README、题目与审阅材料留在运行时检索范围外。未做真实技能开关评测。
