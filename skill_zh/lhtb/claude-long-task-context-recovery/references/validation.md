# 采用前先验证恢复能力

| 用例 | 需要证明什么 |
|---|---|
| 大段工具输出含有很久以后才用的字面值 | 跨过受支持的边界后，从范围正确的笔记或已测试的定位符恢复精确值；不能从当前题面重新猜。 |
| 会话 ID 相同，但服务状态丢失 | 用最小状态检查发现变化，只从已核实来源恢复；不能说任务状态已完整保留。 |
| 新规格只覆盖某个对象或版本 | 按范围应用新值，保留旧证据，并核对面向历史版本的查询。 |
| 编辑入队但未应用，或没有安全的候选 | 不报告已编辑。记录有原因的不操作，或从已知检查点恢复。 |
| 本地摘要写通过，实际产物或验收不支持 | 记录测试输入和分歧；按当前已核证据继续，不按摘要的通过标签继续。 |

有授权做对照时，从同一冻结边界克隆，固定任务、模型、预算和验收。先比较只给工件与工件加检查点；单测编辑时匹配提示、曝光与运行条件，再比较不编辑、只删和删后加作用域笔记。保留原生保护、无效尝试和早停记录。分别量化状态恢复、首个实质动作、不必要重读、实际应用的编辑、输入/缓存/输出及真实验收结果。未经授权，这份用例只供设计审查，不启动实验。
