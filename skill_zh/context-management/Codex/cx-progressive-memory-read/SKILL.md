# 面向决策的渐进读取

适用：原生Codex。状态：轨迹归纳候选，未经独立提分验证。

## 触发
长记忆文件反复占用上下文，当前决策只需要其中一部分。

## 生成与使用
1. 生成短索引，保存实体、版本、有效性、证据位置。
2. 先读索引，只取当前决策相关字段；遇冲突或证据缺失再展开raw，不每次cat全历史。
3. 记录召回内容支持了什么行动、推翻了什么先验或为何不适用。
4. 新有效规则写入当前索引，完整证据另存；不用历史固定行号代替语义地址，定位后核对实体和标题。

## 反馈与修订
统计检索成本、漏检、实际引用及过期误命中。根据反例调整索引，而不是不断扩大默认读取量。用独立任务验证，不以原轨迹成功证明收益。

## 边界与回滚
只减少读入冗余，不删唯一原始来源。保存上版索引；新索引无法恢复关键事实时恢复上一有效版本并补证据定位。不使用评测答案或未来信息，不扩展外部动作权限。
