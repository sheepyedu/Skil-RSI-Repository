# 冲突记忆的当前规则索引

适用：Claude Code CLM。状态：轨迹归纳的候选技能，尚未做独立干预验证，不能承诺提分。只使用当前任务允许的信息，不把评测答案或未来提交写进技能。

## 触发
出现实体切换、版本变化或规则反例时，维护 Claude Code CLM 当前有效记忆。

## 生成与使用
1. 将证据日志与 current-policy 分开：日志保留观察，索引保存当前规则、适用范围、来源、状态。
2. 以任务族、实体、环境版本和观测时间定位，先读索引再读必要证据。
3. 新证据冲突时将旧规则对应范围标 superseded，保留原证据，不简单追加两个矛盾结论。
4. 高风险单位、字段、分母用当前数据廉价复核；同一对手单次结果不足以推出 NEVER/ALWAYS。
5. 压缩时保留反例、未决项和来源指针，不把假设压缩成事实。

## 反馈与修订
记录错误迁移、冲突识别、旧规则撤销及检索成本；只有新可比证据支持时才扩大作用域。 保存变更前版本、证据来源和适用条件；发现反例先收窄或暂停规则，再验证新版本。不要将一次任务成功当成技能有效的证明。

## 边界与回滚
当前规则索引不是隐藏答案表；稳定方法可以迁移，实例值必须按环境核验。 记忆写入失败时保留旧版，不把计划当作成功；恢复只能依据可读取的证据，不能凭印象补全。技能不扩展工具权限或外部动作授权。

## 证据
CCLM-E4、E5；q39/41/43、q48/54、q67/72、q79/81。 参见 [事件与证据](../../EVIDENCE.md) 和 [验证方案](../../EVALUATION.md)。
