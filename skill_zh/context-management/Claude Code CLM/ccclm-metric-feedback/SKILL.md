# 不把跨题分数当策略消融

适用：Claude Code CLM。状态：轨迹归纳的候选技能，尚未做独立干预验证，不能承诺提分。只使用当前任务允许的信息，不把评测答案或未来提交写进技能。

## 触发
根据 Claude Code CLM 的反馈生成或修订技能时使用。

## 生成与使用
1. 记录 task/data/seed、预算、指标定义、可见时间、评价区间；区分即时可见分数与最终官方指标。
2. 不同题的分数差只记录为观察，不推出某策略必然更好。
3. 为失败保留竞争解释，例如信息丢失、旧假设错误、环境变化或指标口径差异。
4. 将新策略标 candidate；安排冻结配置的配对或留出验证，而不是写永久规则。

## 反馈与修订
每次修订关联触发证据和可推翻条件；没有后续验证的规则保持候选状态。 保存变更前版本、证据来源和适用条件；发现反例先收窄或暂停规则，再验证新版本。不要将一次任务成功当成技能有效的证明。

## 边界与回滚
发现集原始值可留在隔离研究证据，不能成为供测试时读取的答案技能。新增付费实验需明确预算。 记忆写入失败时保留旧版，不把计划当作成功；恢复只能依据可读取的证据，不能凭印象补全。技能不扩展工具权限或外部动作授权。

## 证据
CCLM-E3；q97–100。 参见 [事件与证据](../../EVIDENCE.md) 和 [验证方案](../../EVALUATION.md)。
