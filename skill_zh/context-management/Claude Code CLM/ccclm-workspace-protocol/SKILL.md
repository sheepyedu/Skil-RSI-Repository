# 区分持久工作区与官方任务环境

适用：Claude Code CLM。状态：轨迹归纳的候选技能，尚未做独立干预验证，不能承诺提分。只使用当前任务允许的信息，不把评测答案或未来提交写进技能。

## 触发
任务切换、维护恢复或路径及动作参数报错时使用。

## 生成与使用
1. 先识别当前命名空间：本地 Read/Edit/Write/Bash 处理持久笔记；benchmark.act 进入官方任务环境。
2. 在恢复卡记录 cwd、数据版本和实际 action schema，不把官方 /app 当长期存储。
3. 路径不存在时先核对环境再搜索；协议校验失败仅修正字段，不重做已成功任务。
4. 工具报错与领域结论分开记录，下一任务重新验证临时环境路径。

## 反馈与修订
统计误用命名空间、参数重试和缺失笔记；将环境版本变化写入当前索引。 保存变更前版本、证据来源和适用条件；发现反例先收窄或暂停规则，再验证新版本。不要将一次任务成功当成技能有效的证明。

## 边界与回滚
不擅自改变隔离配置、重置官方环境或迁移秘密凭据。 记忆写入失败时保留旧版，不把计划当作成功；恢复只能依据可读取的证据，不能凭印象补全。技能不扩展工具权限或外部动作授权。

## 证据
CCLM-E5；q43、q55、q98–100。 参见 [事件与证据](../../EVIDENCE.md) 和 [验证方案](../../EVALUATION.md)。
