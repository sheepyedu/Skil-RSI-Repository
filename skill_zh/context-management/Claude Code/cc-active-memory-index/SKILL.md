# 分离简短活跃记忆和证据日志

适用：Claude Code 原生长会话，使用其现有 Read/Grep/Write/Edit 与持久notes，不依赖CIM。
状态：来自离线轨迹审阅的候选skill，尚未验证提分。

## 触发
notes逐步膨胀、相同结论在日志/profile重复、规则互相冲突。

## 执行流程：生成 → 使用 → 反馈 → 修订
生成：在原生可用文件工具内维持短active索引和详细证据日志；每条active规则包含范围、证据引用、置信度、失效条件。不要假设存在CLM CIM工具。
使用：默认检索当前实体/任务的active规则，必要时展开证据；压缩优先删除重复叙事，保留当前任务状态、未决项、关键反例和重建路径。
反馈：在压缩前后做问题检查：当前任务下一步是什么、关键约束是什么、每条规则从何而来、何时不能用？不能回答则保留原文或恢复证据。
修订：新事实只追加证据，active规则做定点更新并标记旧版本失效；定期合并同义文件标题但不删除唯一事实。自动conversation compact和磁盘notes整理分开记录。

## 证据
对应事件：CC-N7。详见 [事件与证据](../../EVIDENCE.md)。

## 验证
active记忆长度、唯一事实覆盖率、反例保留率、检索成本；不能只以更短为成功。
使用同任务顺序的开关对照、多随机种子及未参与归纳的留出任务，不把本次原轨迹当新的泛化验证。

## 回滚与权限
保留变更前的记忆版本及证据索引；新规则与当前工具事实冲突时先暂停新规则，从有来源的记录恢复。不恢复已确认过期的任务状态。没有恢复依据则标为未知，不伪造。技能不扩展外部动作授权。
