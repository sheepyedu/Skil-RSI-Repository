# 按语义定位而非历史行号检索

适用：Claude Code 原生长会话，使用其现有 Read/Grep/Write/Edit 与持久notes，不依赖CIM。
状态：来自离线轨迹审阅的候选skill，尚未验证提分。

## 触发
长文件持续追加、多个任务家族或多个实体混杂。

## 执行流程：生成 → 使用 → 反馈 → 修订
生成：建立短索引：family/entity/version/主题→文件与唯一标题；行号仅作本次读取坐标。
使用：Grep定位任务ID或唯一标题，再Read附近，确认实体与版本再引用；写前确认锚点唯一。无相关结果时扩大一次搜索，不将邻近主题冒充所需记忆。
反馈：记录检索发生在决策前还是结果后；事后Read只计编辑准备，不计成功前知识调用。
修订：发现标题/实体错位就更新索引或拆文件；保留旧证据路径，不固定缓存随追加漂移的行号。

## 证据
对应事件：CC-N3。详见 [事件与证据](../../EVIDENCE.md)。

## 验证
正确主题命中率、重复读取次数、决策前有效检索率。
使用同任务顺序的开关对照、多随机种子及未参与归纳的留出任务，不把本次原轨迹当新的泛化验证。

## 回滚与权限
保留变更前的记忆版本及证据索引；新规则与当前工具事实冲突时先暂停新规则，从有来源的记录恢复。不恢复已确认过期的任务状态。没有恢复依据则标为未知，不伪造。技能不扩展外部动作授权。
