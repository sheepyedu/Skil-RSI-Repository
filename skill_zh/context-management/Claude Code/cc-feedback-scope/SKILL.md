# 反馈必须带指标范围且不反演唯一原因

适用：Claude Code 原生长会话，使用其现有 Read/Grep/Write/Edit 与持久notes，不依赖CIM。
状态：来自离线轨迹审阅的候选skill，尚未验证提分。

## 触发
把评分、测试结果或执行反馈写成长期skill。

## 执行流程：生成 → 使用 → 反馈 → 修订
生成：写入反馈的定义、样本/年份范围、是否最终官方分数、比较基线、可见条件；未知项明确写unknown。
使用：只比较同口径指标。aggregate score可能由多个因素共同决定时，列出竞争解释，不用单个分数倒推出唯一增长率、城市系数或缺失产品真实值。
反馈：把成功提交、可见测试通过、最终正确分开；跨题不同数据的分数变化不当作同题消融。
修订：取得更明确评分定义/新证据时纠正旧推论并标记依赖它的规则待重验；保持原观察不变。

## 证据
对应事件：CC-N6。详见 [事件与证据](../../EVIDENCE.md)。

## 验证
错误指标口径次数、不可识别反推次数、同条件重复评估后收益。
使用同任务顺序的开关对照、多随机种子及未参与归纳的留出任务，不把本次原轨迹当新的泛化验证。

## 回滚与权限
保留变更前的记忆版本及证据索引；新规则与当前工具事实冲突时先暂停新规则，从有来源的记录恢复。不恢复已确认过期的任务状态。没有恢复依据则标为未知，不伪造。技能不扩展外部动作授权。
