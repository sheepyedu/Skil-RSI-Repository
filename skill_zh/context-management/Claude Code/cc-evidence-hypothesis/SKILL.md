# 把观察假设规则分层并保留反例

适用：Claude Code 原生长会话，使用其现有 Read/Grep/Write/Edit 与持久notes，不依赖CIM。
状态：来自离线轨迹审阅的候选skill，尚未验证提分。

## 触发
从少量反馈归纳规则、压缩记忆、遇到与旧规则冲突的新观察。

## 执行流程：生成 → 使用 → 反馈 → 修订
生成：分别保存工具观察、模型假设、可执行规则；假设附支持/反对证据、样本数、适用范围和推翻条件。
使用：检索规则时同时读最近反例；对影响当前动作的关键数值/方向做最小校验。无验证的解释不得升级成FINAL或永不更改。
反馈：答案失败时检查是否是错误规则被准确复用，而非先归因遗忘。不要仅因一次赢输把策略认定有效。
修订：新证据冲突时标旧规则superseded并保留原因，更新active规则；压缩保留反例和不确定性，避免只留结论。

## 证据
对应事件：CC-N4。详见 [事件与证据](../../EVIDENCE.md)。

## 验证
冲突检出率、错误假设被当事实次数、规则修订后在独立同条件任务的表现。
使用同任务顺序的开关对照、多随机种子及未参与归纳的留出任务，不把本次原轨迹当新的泛化验证。

## 回滚与权限
保留变更前的记忆版本及证据索引；新规则与当前工具事实冲突时先暂停新规则，从有来源的记录恢复。不恢复已确认过期的任务状态。没有恢复依据则标为未知，不伪造。技能不扩展外部动作授权。
