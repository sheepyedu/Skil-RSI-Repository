# 恢复时对齐摘要与最新状态

适用：Claude Code 原生长会话，使用其现有 Read/Grep/Write/Edit 与持久notes，不依赖CIM。
状态：来自离线轨迹审阅的候选skill，尚未验证提分。

## 触发
原生自动compact之后，或从长会话恢复当前任务。

## 执行流程：生成 → 使用 → 反馈 → 修订
生成：在持久notes中保存任务ID、当前阶段、已完成动作及证据、待办、剩余预算、输出协议和关键数值。只在阶段变化时更新。
使用：恢复时将摘要与最新保留消息、当前工具状态对照，优先采用较新的已验证结果。提交前核对是否已经提交；不要照着摘要把已完成动作重复执行。
反馈：记录出现重复查询、重复提交、遗漏阶段或摘要过期的具体事件，区分完成状态与答案质量。
修订：把易漏字段加入状态卡，删掉无助于恢复的叙事；没有状态接口时保留不确定性，不擅自重做有副作用的动作。

## 证据
对应事件：CC-N1。详见 [事件与证据](../../EVIDENCE.md)。

## 验证
恢复后重复动作率、遗漏待办率和恢复工具次数；保留尾段的原生机制不受该skill控制。
使用同任务顺序的开关对照、多随机种子及未参与归纳的留出任务，不把本次原轨迹当新的泛化验证。

## 回滚与权限
保留变更前的记忆版本及证据索引；新规则与当前工具事实冲突时先暂停新规则，从有来源的记录恢复。不恢复已确认过期的任务状态。没有恢复依据则标为未知，不伪造。技能不扩展外部动作授权。
