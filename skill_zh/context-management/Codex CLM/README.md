# Codex CLM 上下文管理技能

这六项候选技能来自离线 raw 轨迹审阅，不是新干预实验的产物。来源为 Codex CLM 的 100 题运行与相同题序的原生 Codex 对照。仅适用于本仓库自定义 `clm-context` 网关，原生 Codex 不提供此接口。

每项技能描述触发条件及生成、使用、反馈、修订循环，并列出适用边界与回滚。独立验证参见[验证方案](../EVALUATION.md)，[研究证据](../EVIDENCE.md)仅离线查阅。

运行时只复制选定的技能目录。研究证据、事件索引、评测资料及基准答案不得装入被测环境或其搜索路径。
