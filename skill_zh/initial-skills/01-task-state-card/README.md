# 压缩前写任务状态卡

## 归纳环节

在原生 Claude Code 顺序（grouped）与乱序（shuffled）轨迹的离线审阅阶段归纳的 v0.1 初始候选：100 道独立题各执行两次，共 200 题次，包含 19 次原生压缩。这是观察性归纳，不是已验证的改进，也不是 CLM 自主编辑机制的复现。

## 适用范围

任务中途可能压缩、长链工具执行、跨题或跨会话恢复时。

按需使用 [SKILL.md](SKILL.md) 中的操作策略，工具和权限以实际运行环境为准。迁移到其他框架需要验证；该文件夹不代表自动安装了原生技能。

## 使用边界

收益尚未通过消融或留出测试验证。研究证据与评测材料应保持在运行时评测环境之外。本 README 用于说明来源，不必每轮注入上下文。
