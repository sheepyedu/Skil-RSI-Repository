## 实际上下文操作

压缩时机由Claude Code原生阈值触发，摘要由DeepSeek生成。主模型自主选择笔记读写与检索，逐题保留笔记版本和SHA。压缩缩短后续模型输入，磁盘保留完整原始历史。下表记录本地文件工具尝试，笔记目标路径与错误返回在审计文件逐条标注。

| 操作 | 分类顺序 | 打乱顺序 |
| --- | --- | --- |
| Read | 17 | 51 |
| Write | 6 | 23 |
| Edit | 129 | 101 |
| Glob | 3 | 3 |
| Grep | 0 | 2 |

分类组有9/9份摘要正文精确进入紧随其后的模型请求。逐请求端到端输出速率中位数95.75 token/s，链路执行至最后一题封存约144.6分钟。输出速率按API实际completion_tokens除以完整响应时长计算，包含thinking、排队和网络交付。

打乱组有9/10份摘要正文精确进入紧随其后的模型请求。逐请求端到端输出速率中位数85.07 token/s，链路执行至最后一题封存约140.6分钟。输出速率按API实际completion_tokens除以完整响应时长计算，包含thinking、排队和网络交付。

首次实测压缩发生于打乱组第3题。原生记录166840→6525 tokens、29.665秒，随后实际API请求输入10388 tokens。CLI从原始回复选择summary正文的9673字符加入后续上下文，原始analysis和thinking仍完整留档，5份笔记前后SHA一致。

## 条件与解释范围

- 数据为Continual Learning Bench官方固定版本`5f8c50eb1e84b2eda2ef4faff757dfc812a0ea26`。同100题采用两种排列，选题seed为20261116，打乱seed为20261117。排除初始化直接终态题，其余选题与成绩无关。
- Claude Code 2.1.160，API配置模型`deepseek-v4-1-flash-261017`，thinking开启，reasoning_effort为high，统一200,000 token窗口。每题原生上限64轮，任务超时28800秒，API请求超时14400秒。
- 每条链保持同一个session ID、HOME、执行器容器及notes。官方任务沙箱按题目切换。每题通过原生resume继续上一题的上下文。
- 初始技能为空，Skill精炼关闭。后台自动记忆agent关闭，主模型可自主使用Read/Write/Edit/Glob/Grep管理笔记。官方任务操作通过benchmark MCP进行。
- 两条长会话各执行一次。结果支持本次顺序条件下的描述，轨迹包含具体任务答案、环境特征及模型自己的错误，训练采纳尚未审核。

## 完整性与保留问题

- 39个科学源文件SHA通过，Mac和Node各十轮480项CPU检查通过。200题原生整数wait及工具调用/返回已核，全部模型输入转换和原始SSE输出已复核。
- 两种顺序已比较100题官方初始status数据，包含任务描述与响应schema，其中100题完全一致。差异题为`[]`。
- 模型生成的不可用工具名尝试保留原输出与原生错误返回。原生Edit为省略的replace_all补false，逐条记录默认值展开。
- 两次普通任务推理达到32000输出token上限，finish为length且输出全为thinking，随后原生同会话继续并完成对应任务。它们在逐请求表和原始SSE中保留。
- 19份压缩摘要中18份选取正文原样进入后续请求。打乱组请求601→602的摘要中，美元符号紧跟反引号的两字符组合被改为两个换行，其余字符一致。该差异位于原生CLI收到完整响应后重新组装下一输入的边界。独立JavaScript字符串替换夹具可复现此变化，具体CLI源码调用点未定位。原响应和实际后续输入及差异证明均保留于CONTEXT_SUMMARY_RECONCILIATION.json。
- 本地辅助token计数路由共有37份拒绝记录，具体路由与错误在逐组audit文件。它们未转发到模型API，原生CLI回退后继续。
- 两个科学worker的真实wait均为0，逐题原生进程已核终态，两个自有执行器容器已按精确CID清理。根owner父进程wait未单独留存，原完成记录与/proc终态另列。
- 容器收尾首次核验因错误文字大小写比较失败。分类容器已实际移除，按原清理意图、原inspect和精确缺席协调，未保存的该次rm整数回执保持null；打乱容器按原范围完成清理。原失败和协调证据均保留。
- 使用量按实际API回执统计，输入累计包含历史在各轮请求中的重复传入。货币账单未提供，保持null。CLI美元估算单独保留在原日志。
