# 记忆写入必须核验成功

适用：Claude Code 原生长会话，使用其现有 Read/Grep/Write/Edit 与持久notes，不依赖CIM。
状态：来自离线轨迹审阅的候选skill，尚未验证提分。

## 触发
Read/Write/Edit记忆文件，尤其压缩后。

## 执行流程：生成 → 使用 → 反馈 → 修订
生成：先确定目标文件与最小变更，不把工具调用意图当成已写入。
使用：读工具返回。未读错误→Read当前目标；锚点不存在→重新读取原文；多处匹配→加入唯一任务ID/标题上下文。只在原意确实为全部替换时用replace_all。随后重试最小修改。
反馈：以成功返回和必要的目标片段复读确认内容，失败留在待办，不宣称记忆保存成功。
修订：为常改段落加入唯一ID；一个错误不要无变化重试，不要为修复一次Edit改成覆盖整个旧文件。

## 证据
对应事件：CC-N2。详见 [事件与证据](../../EVIDENCE.md)。

## 验证
未读/锚点错误次数、修复调用开销、意图与落盘不一致数。
使用同任务顺序的开关对照、多随机种子及未参与归纳的留出任务，不把本次原轨迹当新的泛化验证。

## 回滚与权限
保留变更前的记忆版本及证据索引；新规则与当前工具事实冲突时先暂停新规则，从有来源的记录恢复。不恢复已确认过期的任务状态。没有恢复依据则标为未知，不伪造。技能不扩展外部动作授权。
