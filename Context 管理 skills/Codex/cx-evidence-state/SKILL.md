# 原始证据与聚合状态分离

适用：Codex。状态：轨迹归纳的候选技能，尚未做独立干预验证，不能承诺提分。只使用当前任务允许的信息，不把评测答案或未来提交写进技能。

## 触发
反复累计观测、匹配实体或使用历史统计量时使用。

## 生成与使用
1. 原始观测保存时间、来源与实体候选；聚合状态使用稳定entity_id、计数、统计量和假设状态。
2. 冲突时保存替代关联，定义复核条件；不能只写uncertain而继续无条件合并。
3. 有可比新证据时复核/拆分/撤销；暂时不出现不等于长期实体过期。
4. 优先读取聚合索引，需要解释冲突时才读取raw。

## 反馈与修订
检查统计量能否从证据重算、误合并撤销率和读取成本。 保存变更前版本、证据来源和适用条件；发现反例先收窄或暂停规则，再验证新版本。不要将一次任务成功当成技能有效的证明。

## 边界与回滚
不强迫所有领域永远保留全部历史；只保留任务允许且可影响决策的证据。 记忆写入失败时保留旧版，不把计划当作成功；恢复只能依据可读取的证据，不能凭印象补全。技能不扩展工具权限或外部动作授权。
