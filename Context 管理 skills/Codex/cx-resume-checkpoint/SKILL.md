# 原生压缩恢复契约

适用：Codex。状态：轨迹归纳的候选技能，尚未做独立干预验证，不能承诺提分。只使用当前任务允许的信息，不把评测答案或未来提交写进技能。

## 触发
原生 Codex 长会话中断、自动压缩或阶段交接时使用。

## 生成与使用
1. 保存 active-state、executed-receipts、next-step、reusable-evidence、unresolved 五段，附当前任务、剩余预算与协议。
2. 恢复后结合摘要、保留尾段、当前status核验，先检查提交是否已经发生。
3. 只继续未完成义务；建议动作与已执行动作分开。旧领域细节留文件索引而非不断塞进摘要。

## 反馈与修订
记录重复副作用、遗漏义务和恢复调用数；正常续跑与最终评分分别报告。 保存变更前版本、证据来源和适用条件；发现反例先收窄或暂停规则，再验证新版本。不要将一次任务成功当成技能有效的证明。

## 边界与回滚
不能控制原生compact具体时机或保证摘要完整；有冲突时优先较新可信回执。 记忆写入失败时保留旧版，不把计划当作成功；恢复只能依据可读取的证据，不能凭印象补全。技能不扩展工具权限或外部动作授权。
